# STEP → CadQuery 序列重建

从 STEP **读取、测量、理解设计，再用 CAD 特征重建并验证**。交付可运行的序列代码，而不是 STEP 转换器。此 Skill 独立使用，无需同时加载英文版。

## 硬性规则

- **分析与生成隔离：** 分析/验证程序可以导入 STEP 查询几何；最终建模程序不得读取 STEP、BREP、STL、网格或原始 Shape 缓存。仅把有设计含义的测量参数写入代码。
- **特征建模，不是几何搬运：** 禁止复制原 Face/Edge、缝合原拓扑、嵌入 B-rep 数据、搬运样条极点或点云/曲面拟合。剖切用于测量，不能把截面几何直接转存为输出。
- **逐个实体、顶层执行：** 命名草图、实体与切削工具；直接使用 CAD 操作，再显式 `union/cut/intersect`。不写自定义建模函数、`lambda`、工厂类或 `build_model()`；分析、验证和渲染工具可使用函数。
- **真实序列：** 按设计需要选择操作，不为凑种类强加特征，不用巨大坐标表或解释器隐藏建模。`Compound/Assembly` 只能组合已经由特征生成的体。
- **不偷换精度：** 不擅自省略小圆角、归零倾角、强制同轴/镜像或用近似曲面替代。无法满足公差时说明原因，请用户批准近似；未经批准不得以近似结果宣称完成。
- STEP 通常不包含原始特征历史，重建序列也不唯一；不要声称恢复原历史树或保证任意自由曲面都可精确参数化。

## 1. 检查输入与环境

- 接收完整 `.step/.stp` 或原样保存完整粘贴文本。核对 HEADER/DATA、结束标记、实体编号唯一性、引用完整性和外部装配文件；遇到截断/缺失不得补造实体，索取完整输入。
- 保留源文件及哈希；检查 CadQuery/OCP 和渲染工具。
- 查明 STEP 单位上下文、导入后的单位、实例坐标变换。默认输出 mm，确认所有零件/实例都在范围内。

## 2. 测量并规划

- 对每个逻辑体记录：坐标系、包围盒、体积/面积、质心、面型、孔槽、轴线、半径、厚度、倾角、对称性与装配关系。区分测得参数和推断参数。
- 建立简短表：`阶段 | 目标体 | 平面/草图 | CAD 操作 | 参数值/单位/测量依据 | 预期结果/公差`。先测量与推理，再写代码。
- 用户公差优先；未给定时声明临时诊断门槛，例如线性偏差 0.01 mm、相对体积差 1e-4，并按尺度与关键配合调整。它们不是通用制造标准；不得为通过检查而放宽门槛。

## 3. 选择特征并逐体构建

| 设计证据 | 优先操作 |
|---|---|
| 恒截面、共轴回转轮廓 | Sketch + Extrude；半剖面 Revolve / Revolve cut |
| 沿曲线路径或变截面过渡 | Sweep；Loft，明确截面、导轨与姿态，不以拟合代替推理 |
| 圆滑/斜面边缘、薄壁 | Fillet；Chamfer；Shell 或外体减内体 |
| 通孔、盲孔、阶梯孔、局部切除 | Hole / 沉孔；独立工具体 + Boolean cut |
| 经测量证实的重复/对称 | Rectangular/Circular pattern；Mirror |
| 定位、组合、去除工具体 | Construction plane；Transform；Union/Cut/Intersect；排除不保留的体 |

- 每体先构造基体，再添加/切除、孔槽与局部修饰；根据特征依赖安排顺序。`delete body` 是从结果集合排除工具/临时体，不是删除输入文件。
- 只融合应该连成同一实体的部件。原 STEP 的 solid 数不一定等于设计零件数，分件变化必须解释并建立源区域映射。
- 选 fillet/chamfer 边依据方向、位置、类型、长度或邻接面，并断言数量；不依赖易变的边编号。操作失败先查尺寸和选择器，不能吞异常跳过。
- 通切工具适当越过入/出面以避免重合面失败，但不改变盲孔深度或最终尺寸；避免近相切布尔，检查切除是否真的发生。将脆弱圆角后置，但以真实特征依赖为准。
- 每一步保存 Shape 快照到有序 `history`，检查 `isValid()`、正体积、预期实体数和增减料效果。最终暴露 `result`、`bodies`、`history`；参数单位显式，统一转换一次。

## 4. 独立重放与精度闭环

1. 检查生成代码及依赖，排除源几何/动态导入/编码数据和隐藏建模封装。审查后在无源 STEP、无几何缓存的新目录独立运行；不得执行未经审查的外部代码。
2. 导出重建 STEP 后重新导入；按逻辑体对照原坐标中的关键尺寸、位置、孔/壳连通、包围盒、质心、面积和体积。面数不同只是诊断，不自动判错；不要自动对齐来掩盖位置误差。
3. 计算 `source.cut(rebuilt)` 与 `rebuilt.cut(source)`，分别报告缺料/多料及对称差体积；只统计实际 solid 体积，相对值以原体积为分母。布尔失败不是零误差。
4. 双向检查表面偏差：从各面取样，求点到另一模型**表面集合**的距离，报告最大采样距离及位置、采样密度/方法，并对小孔、薄壁、圆角和热点加密复测。整体 Shape 的最小距离不是最大偏差；有限采样也不证明全表面误差上界。
5. 失配先排查单位/变换，再定位基体、孔槽、倾斜/偏心和圆角等具体阶段；修正后重放并复验全模型。分开记录 CAD 重建误差和 STL 网格误差，不以网格加密修复错误 CAD。
6. 公差未达标、输入不全或验证受限时明确标记，不写“完全一致”。任意 STEP 的高精度不能只靠 Skill 保证，必须由本次实测支持。

## 5. 交付与可视检查

- 实际生成 `model_sequence.py`、参数/特征表、`model_rebuilt.step`、`model.stl`、`validation.json`、运行说明及图片；需要分件时另外导出。运行说明列依赖、命令、单位、精度与已知限制。
- 以重建 STEP 为 CAD 验证依据，STL 为派生网格；验证 STL 所有分量水密、法向一致、体积为正，记录网格参数。源码、原始输入与派生产物分开，不能误把旧导出当作新结果。
- 将原 STEP 与**重建 STEP**用相同视角分别渲染并查看：相对的等轴视图、必要的正交/剖视及阶段图。STL 另用于检查离散效果；不能用源图或 STL 图替代重建 CAD 检查。
- 把每个视觉疑点转为尺寸/拓扑检查；只修正负责的序列段，重新生成并复测失败项和可能受影响的邻近特征。报告只写实际执行的检查。
- 给可下载代码/模型包和已检查图片。只有独立重放、几何验证、导出重读与可视检查都有证据才宣告完成；体积接近、水密、有效实体或外观相似均不能单独证明准确。
