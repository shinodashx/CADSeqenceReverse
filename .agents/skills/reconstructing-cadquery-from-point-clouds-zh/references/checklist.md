# 建模与验收检查表

## 输入和测量

- NPY：`allow_pickle=False`，实数 N×3；额外列明确指定，3×N 不自动转置。PLY：按 x/y/z 字段读取 ASCII／二进制，忽略并记录 faces／颜色／法线。文本：三元组数组或逐行空格／逗号 XYZ，不用 `eval`。
- 原始索引为从 0 开始的数据行／vertex 索引；无效点默认拒绝，若另行清理必须记录原因与映射。保留重复点，同时用唯一点／空间分区统计避免密度偏置。
- 单位未知时保留原尺度并标未知；若暂按毫米输出，说明是假设。记录单位换算和刚体变换，点云、模型、阈值处于同一坐标系。PCA 不证明左右手／轴正负，不能用 ICP 静默移动模型降低误差。
- 孔必须有孔壁／边界证据，缺点不等于孔；窄弧不足以稳定确定半径。平直区和折弯区分别测厚，旋转件分别测端面、凹槽与台阶。阵列／镜像先验证再施加。
- 局部参数优化保持少量、可解释。复杂自由形状只有在截面有证据时才用少量控制点的 Sketch/Sweep/Loft，并声明近似；不逐点插值追噪声。数据不足时索要截面／尺寸。

## 序列与圆角接合

- S 步骤写清“输入 body → 基准和草图 → 参数化操作 → 输出 body → 检查”。保留命名中间结果，不导入旧实体。输出是新建的可重放序列，不是唯一原始特征树；STEP 不保存 Python 特征历史。
- 检查工作平面法向、挤出方向、Revolve 轴、Sweep 截面方向、Loft 截面对应与扭转、Shell 开口／壁厚、阵列相位和变换顺序。
- 相接处先排除基准错位、壁厚错误及低精度截断造成的薄片／微台阶，再决定是否圆角。不能把部件运动间隙“抹平”。
- 受力凹根常在 Union 后、孔槽前做；倒角通常在根部圆角后做。按局部拓扑调整，不机械地把所有圆角放最后。
- 用 body、几何类型、坐标／方向／半径和邻面选边，验证数量与位置；避免不稳定边索引或全局无差别 `edges().fillet()`。
- 圆角失败检查半径、邻面、薄壁和特征次序，不能 `try/except: pass`。圆角加／减料后复查壁厚、干涉和切点；高光连续不等于几何相切。
- 轴承座、摩擦面、定位端面、导销孔保留必要平面与配合。刀具体不导出；delete body 是活动对象／装配清单排除，不冒充原生删除历史。

## 精度与最终实体

- 根据单位、测量噪声和用途确认表面／关键尺寸目标；点间距不是测量精度。没有目标就报告统计，不宣称通过绝对精度验收。
- 全量及分区报告 N、平均、RMS、中位数、P95、最大值、阈值内比例和最差原点索引。不能删异常点提高分数；先检查孔壁、接触面及建模错误。
- 默认距离是单向无符号点→最近三角面，不是最近顶点，也不是双向 Hausdorff。模型→扫描样本只在已观测区域帮助发现多余面；扫描稀疏／遮挡处标未知。
- 保存 STL 线性／角度离散参数；细化网格复算确认收敛。用 STEP **Faces** 的 Compound 复核关键点，不能用实心体距离把内部点误判成零。子集复核必须标明数量，不能冒充全量。
- 融合会消除接触面：分别验证部件表面与最终融合体。本次脚轮实践中确实发生过这种误差差异，不能只展示较小的那个。
- 干净进程重跑序列，STEP 重新导入检查有效性、实体数、关键位置和尺度。单件 STL 检查封闭、朝向、退化面、正体积；用截面／探针检查孔槽贯通与壁厚。
- `verify_surface.py` 只提供全量三角面残差和可选 STEP 复核；须另外完成反向覆盖、区域语义、STL 完整性和装配检查。`--require-within-fraction` 只验收所声明的表面阈值比例，不代表所有质量门通过。
- 查看真实 CAD 导出物的整体／背面／截面／接合放大图及残差分布；修改圆角时同机位前后对比。未渲染或未查看就明示限制，不用 AI 图片代替。

## 装配和改型（仅在需要时）

- 保留固定／旋转／浮动件及各自轴线、行程、止挡和父子变换。不要融合运动件后整体旋转伪装机构。
- 检查释放、接触、极限姿态及角度采样；两两正体积干涉不能静默豁免紧固件。离散检查不是连续扫掠证明，动画不是摩擦／制动力学仿真。
- 忠实重建先保存基线；胎纹、制动机构等功能改型另建序列，按新设计目标验收，不宣称原点云证明了新增结构。
- 报告必须包含单位／变换、目标、误差定义、检查命令与结果、近似区域、输出文件；不把静态接触当夹紧力，也不保证载荷、抓地力或制造公差。
