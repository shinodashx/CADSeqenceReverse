# 建模与验收检查表

## 输入与证据

- NPY 用 `allow_pickle=False` 读取实数 N×3；额外列显式指定。PLY 按 x/y/z 字段读取 ASCII／二进制顶点，记录其余属性被忽略。文本安全解析三元组数组或逐行 XYZ。
- 保留坐标、行序、重复点和从 0 开始的原索引；无效数据先报告，清理另存原因与映射。程序校验输入完整性，点云特征证据来自实际查看的渲染图。
- 单位未知时保留原尺度并声明假设；用图上标尺或已知尺寸目视估计。保持点云与 CAD 的共同坐标系，记录变换；相机取景只改变显示。
- 分别观察内外壁、端面及过渡；孔依据孔壁或边界视图，阵列／镜像依据多视图一致性。记录短弧、稀疏与遮挡的不确定性；自由曲面使用有截面视图依据的少量控制参数。

## 序列与接合

- `feature_plan.md` 统一范围、基准、未知量和可观察目标；每步记录输入 body、草图／基准、参数、操作、输出及检查。点云数值精度标为“未评估”。
- `sequence_cq.py` 是几何源，导出物由其重建。保留命名中间结果；交付的是新建可重放序列，Python 文件保存操作历史。
- 检查平面法向、挤出方向、回转轴、Sweep 截面方向、Loft 对应关系、Shell 开口／厚度、阵列相位和变换次序。
- 相接处先核对 CAD 基准、切点、壁厚、运动间隙与薄片，再安排局部 Fillet／Chamfer。按邻接拓扑和后续特征确定顺序。
- 按 body、几何类型、位置／方向／半径及邻面选择边，核对数量和位置。圆角失败检查半径、薄壁与操作顺序；修改后复验 CAD 相切、壁厚、孔槽和干涉。
- 保留功能面的配合；刀具体留作中间结果。Delete body 对应活动 body／装配清单排除，导出最终保留件。

## 分层验收

- 干净进程重跑；所有交付部件及融合变体分别检查有效 BRep、预期实体数、正体积、关键 CAD 尺寸、孔槽贯通和壁厚。STEP 重导入复查尺度与位置；STL 检查封闭、朝向、退化面和体积。
- 全量点提交绘制，以正交、相反斜视、背面、局部显示切片覆盖关键区域；记录可见与遮挡范围。点云与 CAD 按相同坐标、相机、比例及裁切并排观察，保留未裁切整体视图。
- 逐视图／逐区域记录轮廓、开口、连接及过渡的一致性，尺寸来自标尺的目视估计。局部裁切仅用于显示；反向视角辅助判断接触及遮挡面。
- 保存 STL 线性／角度离散参数，细化显示复查棱角，并用 CAD 的 BRep 截面检查模型结构。点云图像比较与新建 CAD 的内核数值检查分别记录。
- 多实体检查两两相交体积、配合间隙及数值容差，定位处理正体积干涉。运动按需保留独立部件、轴线、行程及父子变换，检查接触与极限姿态；注明离散采样及工程性能评估范围。
- 查看实际导出物的正交、相反斜视、截面和接合放大图；修改圆角时同机位对比。部件和融合变体分别检查，解释接触面消失的影响。
- 渲染工具提供视图；CAD 有效性、网格完整性及装配由内核另行检查。需要点云数值精度认证时说明本模式的评估范围，并由用户确认切换分析模式。
- 按 [迭代流程](refinement.md) 修正未达标项。报告绑定源文件、渲染命令／截图、序列及导出物哈希，包含检查结果、目标状态和剩余近似；功能改型与忠实重建分别交付。
