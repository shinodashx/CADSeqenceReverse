# 通用重建与迭代

## 选择特征

- 以相同原索引区域比较平面／圆柱、直线／圆弧、挤出／回转、等厚偏置／独立内外壁。记录支持点、覆盖及残差，用空间分离的数值截面复核候选。
- 分别检验端面法向、内外壁、相切点和重复变换，再选择操作。沿直线不变的截面支持 Extrude／Sweep，绕轴不变的截面支持 Revolve，变化截面支持 Loft。
- 分别保存测量值、采用值及最终 CAD 距离，量化取整和简化影响。依据截面一致性与残差结构选择少量可解释参数，记录不可辨识的尺寸。

## 每轮闭环

1. **保存基线。** 保存序列、证据、参数变化、检查结果及哈希；固定输入、坐标系、单位、目标、区域和离散设置。
2. **定位责任。** 用数值表检查超差点及空间聚集，追溯到首个异常 S 步骤。区分输入／尺度、特征假设、尺寸、选择器／拓扑、操作次序和导出／验证问题。
3. **提出修改。** 写明反证、候选操作及预期改善区域；先修正特征类型，再调整相关尺寸。只改责任步骤与必要依赖，保留已验证特征。
4. **重建检查。** 从序列重新生成；拓扑变化后刷新选边／选面规则并核对数量。先复查失败项，再检查所有交付实体、孔槽、壁厚及装配。
5. **同条件复验。** 对全量点、修正区、原合格区及关键特征比较检查表中的全部指标；细网格与 STEP 面复核用于区分几何和离散误差。另查看纯 CAD 导出物检查建模质量。
6. **评估候选。** 保留几何有效、证据支持且满足关键约束的改善；记录局部退步和逐轮比较。继续修正可定位问题，最终报告使用当前产物的检查结果。

## 接合与验证诊断

- 先处理坐标截断、非相切草图、薄片和错位，再按单位、最小特征及目标选择内核容差；调整后复查体积、孔槽与干涉。
- 圆角的加／减料效果用切点、数值截面、邻面和局部残差验证。零件归属由原索引分区与坐标覆盖复核，模型干涉由 BRep 相交体积检查。
- 验证器或旧产物出现问题时先修复检查链，再评价模型；点云证据与残差全程以数值处理。

## 结束条件

- **达标：** 全局／局部及关键尺寸目标满足，实体、网格、装配与导出检查通过，纯 CAD 渲染已查看。
- **受限：** 对替代结构与数值误差检查后仍存在不可辨识参数或持续退步，保存最佳有效近似，列出剩余区域／原索引、已试候选及所需截面、尺寸或加密数据。
- 交付可重放序列、可复算证据与验证命令、逐轮比较及最终文件哈希。
